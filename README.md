# Experience-and-insights
# 学习过程中的一些心得体会
   缘起，2026我买了一台8845的机器。用它玩了PS3的神海2，神海3后，觉得索然无味。想起AMD猛吹的NPU，以起最近很火的AI，于是尝试部署起来。
   下载了LMStudio用起来，用起来不错，摸索了一段时间后，用起来不错，后来发现NPU完全不干活。找了AMD的文档，没细看，AMD推荐FastFlowLM，Lemonade。于是吭吃吭吃去下载软件，下载模型。部署好后，一看NPU还是不干活。
   
# 780m 显卡 须用 24.5.1 版本，使用正常，玩新游戏没有异常，就不要升级了。
  之前玩PS3模拟器的时候就烟雾和火焰的效果贴图效果很奇怪。平面贴图，没有透明效果，纯纯五毛特效。改用opengl接口效果正常，但有鬼影。开始还觉得是模拟器的问题。但又觉得那里不对。依稀想起，yuzu模拟器的升级报告中有提到，AMD更新驱动会也出现了问题。搜索了一下才发现，除了这个版本，其它版本或多或少都有问题。
